# Alpha Sporting — E-commerce con JavaScript

Tienda online de indumentaria deportiva desarrollada con HTML, CSS y JavaScript. El proyecto permite explorar productos, filtrarlos por categoría y gestionar un carrito de compras persistente.

**Demo:** [integrador-js-lovat.vercel.app](https://integrador-js-lovat.vercel.app/)

## Funcionalidades

- Catálogo de productos generado dinámicamente.
- Filtros por categoría.
- Botón para cargar más productos.
- Carrito con suma, resta y eliminación de artículos.
- Cálculo automático del total de compra.
- Persistencia del carrito mediante `localStorage`.
- Menú y carrito adaptados a dispositivos móviles.
- Pantallas de inicio de sesión y creación de cuenta.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Local Storage

## Ejecutar el proyecto localmente

```bash
git clone https://github.com/Antonellavve/IntegradorJS.git
cd IntegradorJS
```

Después, abrí `index.html` en el navegador o utilizá una extensión como Live Server.
